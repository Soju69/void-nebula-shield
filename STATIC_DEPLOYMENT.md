# 📦 Инструкция по развертыванию статической версии VOID VPN

## ⚠️ ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ О БЕЗОПАСНОСТИ

**Статическая версия с аутентификацией на клиенте НЕ БЕЗОПАСНА для продакшена!**

### Почему это небезопасно:
1. ❌ Хеши паролей видны в исходном коде на клиенте
2. ❌ Проверка аутентификации происходит на клиенте и может быть обойдена
3. ❌ Нет защиты от brute-force атак
4. ❌ Нет серверной валидации данных
5. ❌ localStorage может быть легко изменен

### Используйте статическую версию только для:
✅ Демо и презентаций
✅ Локальной разработки
✅ Прототипирования

### Для продакшена используйте:
✅ Lovable Cloud (встроенный Supabase)
✅ Полноценный backend с серверной аутентификацией

## 🚀 Шаги развертывания

### 1. Настройка администраторов

Откройте файл `src/config/admin-config.ts` и настройте список администраторов:

```typescript
export const ADMIN_USERS: AdminUser[] = [
  {
    username: 'admin',                    // ← Ваш логин
    passwordHash: '$2a$10$YourHashHere', // ← Хеш вашего пароля
    role: 'admin'                         // ← Роль
  },
  // Добавьте больше администраторов...
];
```

### 2. Генерация BCrypt хешей паролей

**Вариант A: Онлайн генератор (быстро)**
1. Откройте https://bcrypt-generator.com/
2. Введите ваш пароль
3. Выберите rounds: 10
4. Скопируйте сгенерированный хеш
5. Вставьте в `passwordHash` в admin-config.ts

**Вариант B: Node.js (безопаснее)**
```bash
# Установите bcryptjs
npm install bcryptjs

# Создайте файл generate-hash.js:
const bcrypt = require('bcryptjs');
const password = 'ваш-пароль-здесь';
const hash = bcrypt.hashSync(password, 10);
console.log('Хеш:', hash);

# Запустите:
node generate-hash.js
```

### 3. Установка зависимостей для bcrypt (опционально)

Если хотите использовать настоящую bcrypt проверку на клиенте:

```bash
npm install bcryptjs
```

Затем раскомментируйте код в `src/lib/static-auth.ts`:
```typescript
// Найдите и раскомментируйте:
const bcrypt = await import('bcryptjs');
return await bcrypt.compare(password, hash);

// И закомментируйте mock проверку:
// return password === 'admin123';
```

### 4. Настройка конфигурации

#### Telegram интеграция
В файлах где используется Telegram, найдите и замените URL:
- `src/pages/Index.tsx` - кнопки Telegram Bot и канал
- URL канала: `https://t.me/your_channel`
- URL бота: `https://t.me/your_bot_username`

#### VPN конфигурации
В `src/pages/PaymentSuccess.tsx` замените:
```typescript
// Найдите:
const MOCK_VPN_CONFIG = {
  server: 'void-server-01.example.com',
  // ...
}

// И замените на ваши реальные данные сервера
```

### 5. Сборка статической версии

```bash
# Установите зависимости
npm install

# Соберите проект
npm run build

# Результат будет в папке dist/
```

### 6. Развертывание

Загрузите содержимое папки `dist/` на ваш хостинг:

**Популярные варианты:**
- **Netlify**: Перетащите папку dist в интерфейс
- **Vercel**: `vercel --prod`
- **GitHub Pages**: Загрузите в gh-pages branch
- **Обычный хостинг**: Загрузите по FTP/SFTP

## 🐛 Отладка

### Проверка аутентификации
Откройте консоль браузера (F12) и посмотрите сообщения:
- ✅ Успешная аутентификация: username
- ❌ Пользователь не найден
- ❌ Неверный пароль
- ⏰ Сессия истекла

### Проверка localStorage
```javascript
// В консоли браузера:
localStorage.getItem('void_admin_session')
```

### Очистка сессии
```javascript
// В консоли браузера:
localStorage.removeItem('void_admin_session')
```

   - `TELEGRAM_CHANNEL_ID`
